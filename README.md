# game-creator

A Web app that alows users to generate games from templates. There are pre-defined templates and the user chooses different options and then a custom game is generated from a template.

## Documentation

Full documentation (architecture, module reference, template anatomy, testing, ADRs) is published with MkDocs: <https://kjenney.github.io/game-creator/>

## Architecture

The game templates use Babylon.js which creates a web app to host the game.
